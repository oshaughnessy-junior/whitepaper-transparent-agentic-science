## Reproduce the tooling case

Requires Python 3.10+ and Make; no scientific Python packages are required.

```
make check
make paper                  # requires a LaTeX installation with REVTeX 4.2
make submission             # builds an arXiv-source candidate, not an upload
```

The synthetic tooling case computes a known integral by two routes and generates the numerical macros and table used by the note. `make check` verifies generated bytes and exercises intentional corruption. This is a consistency demonstration, not a benchmark of agent scientific ability.

## Scope

- Evidence source: `agent-skills`, with the canonical writing procedures followed into `research-skills`.
- Example papers: the main papers in [popsynth_hyperpipe_paper](https://github.com/oshaughnessy-junior/popsynth_hyperpipe_paper) and [gwk-hierarchical-initial](https://github.com/oshaughnessy-junior/gwk-hierarchical-initial). Both repositories currently require access; their main preprints are public.
- These source repositories are private at the time of inspection. This public repository contains newly written procedure summaries, a public source map, and an original synthetic demonstration; it does not redistribute their unpublished results or full contents.
- Additional example: the [RIFT development PR sequence](https://github.com/oshaughnessy-junior/research-projects-RIT/pulls), with concrete merged repairs linked in the note and [case inventory](cases/README.md), and the public [third-generation RIFT main paper](https://arxiv.org/abs/2609.37393). Follow-on studies are identified as future work.
- Additional code example: public [NuclearMatter-Backend](https://github.com/oshaughnessy-junior/NuclearMatter-Backend), with dated solver-validation records and operational lessons from CIT, cardassia, and sporc in the [case inventory](cases/README.md).
- Case studies are not certified replications until their run records, checks, and suitable public evidence are attached.

## Skills

The [full skill-port assessment](docs/skill-port-assessment.md) screens all top-level agent-skills packages and recommends essential additions. The essential, sanitized additions are now included; see the [port record](docs/skill-ports.md) for tools, licenses, tests and scope.

The nine portable packages in `skills/` cover **result provenance**, **simulation validation**, **adversarial scientific review**, **scientific writing**, **bounded editing**, **citation verification**, **bibliography auditing**, **research cycles**, and **durable records**. The note maps these skills to the supporting practices, including paper-example reproduction, previous-code and literature comparisons, and production-environment checks. They are deliberately separate from machine-specific access, runtime memory, credentials, and submission policies.
