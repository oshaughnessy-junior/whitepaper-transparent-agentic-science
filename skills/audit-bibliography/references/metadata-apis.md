# Metadata request boundary

Identifier resolution uses public scholarly services. Provider availability, authentication and rate limits can change; consult their current official documentation before relying on throughput assumptions. Respect service limits and report failed requests explicitly.

Prefer identifier-pinned publisher/registrar metadata, arXiv or ADS as appropriate. Search matches are candidates for inspection, not proof of fabrication or source support. A miss in a secondary index does not establish absence from the literature. Preprint and published metadata can legitimately differ.

Send only shareable identifiers and search terms. Read credentials from environment variables. Review generated reports for private research selections before releasing them. Do not publish caches or local query history automatically.
