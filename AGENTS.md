# Repository contract

This PUBLIC repository is entirely assembled with AI from prior human collaboration. All commits are performed by AI agents. Preserve that disclosure and add `AI-Generated: true` and `Agent: <actual agent>` commit trailers. Use an explicit agent git identity; never impersonate human scientific approval.

Edit paper/main.tex in place. Document observations separately from proposed practice. Keep private inputs and raw memory out of the public tree. Publish new procedure summaries and sanitized evidence only. Do not change source-repository visibility.

Computed results in the manuscript, captions, and tables must be generated from one versioned result record. Run `make check` after changes. A green build certifies only the checks it actually ran. Do not report an independent review unless an independent reviewer completed it on the stated candidate.

Preserve finding dispositions and claim retractions. Submission packaging is not authorization to submit. Verify the current official venue requirements before an actual submission.
