# Lessons recovered from project memory and run locations

Read-only inspection informed this newly written public procedure summary. Private source identifiers, paths, revision histories, raw memory, transcripts, collaborator details and unpublished numerical findings are excluded. Detailed audit information is retained locally for human review. Recorded memory is evidence that a lesson was recorded, not a fresh replication.

| Failure pattern | Operational practice |
|---|---|
| A striking result reaches an abstract before stability checks | Resample and refine before promotion; keep partial results in notes |
| A physical explanation conceals an input-representation error | Audit posterior versus likelihood, prior division, coordinate measure, covariance and selection before interpreting a tension |
| A comment asserts a setting the launcher did not supply | Write effective settings into the output and compare them with the scientific specification |
| A convention changes in only some callers | Enumerate callers, launchers, sidecars, plots, summaries and prose; demonstrate semantics end to end |
| Cache identity follows log text | Assign identity at construction and assert a physical invariant before writing |
| A cache omits calibration dependencies | Hash the dependency closure, reject unstamped products, and validate through a maintained accessor |
| A reported fit depends on an unrecorded optimization schedule | Preserve initialization, phases, restarts, checkpoints and the rule selecting the reported iterate |
| Monte Carlo noise is assigned to the wrong cause | Separate finite-library support, integration sampling and configuration effects before proposing repairs |
| A green check did not execute its target | Verify tool availability, stage output, collected cases and a relevant failure control |
| Final edits restore superseded claims | Repeat provenance and retraction sweeps after the last human or collaborator change |

Promoting an independent numerical backstop into production requires an explicit interface, configuration identity and validation domain. A prototype can expose a defect without being ready to replace the production path.
